# Network Intrusion Detection System (NIDS)

## Project Overview
Network Intrusion Detection System is a web-based security application that monitors network activities and detects suspicious events.

## Features

- User Registration
- User Login & Logout
- Network Event Monitoring
- Threat Detection
- Alert Management
- Dashboard with Network Logs

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Project Structure

NIDS/
│
├── app.py
├── config.py
├── database.sql
├── models/

└── static/

## How to Run Project

1. Install requirements
2. Start MySQL database
3. Run Flask application
4. Open browser
http://127.0.0.1:5000
## Modules
### Authentication Module
Handles user registration, login and logout.
### Monitoring Module
Stores and displays network events.
### Alert Module
Displays detected threats and alerts.
### Dashboard Module
Shows network statistics and logs.
